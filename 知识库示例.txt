Python 与 RAG 基础知识

一、变量
变量是存储数据的容器，用等号赋值，例如 age = 24。
变量名要达意，推荐用英文或拼音。

二、数据类型
整数 int：24、100
小数 float：3.14
字符串 str：用引号包住的文字，例如 "你好"

三、条件判断
if 条件:
    做某事
elif 其他条件:
    做其他事
else:
    都不满足时执行

四、循环
for i in range(1, 6)：循环 5 次，i 依次为 1 到 5。
while 条件：条件成立时一直循环，可用 break 跳出。

五、列表
列表用方括号，例如 [12.5, 8, 20]。
append 添加元素，len 数个数，sum 求和，下标从 0 开始。

六、函数
def 函数名(参数):
    return 结果
函数把一段代码打包，可以重复调用。

七、RAG 检索增强生成
RAG 的流程是：先把文档切块并向量化，提问时检索最相关的内容，再把检索结果和问题一起交给大模型生成答案。
RAG 能减少幻觉，因为答案来自给定资料，而不是模型凭记忆编造。
