# AI Agent 智能体

## 什么是 Agent
Agent 是能自主决策、调用工具完成任务的 AI 程序。
普通聊天机器人只能回答，Agent 能做事。

## Agent 的核心循环
第一步，用户提出问题。
第二步，把问题和大模型可用的工具清单一起发给大模型。
第三步，大模型判断需要调用哪个工具，返回工具名和参数。
第四步，程序在本地执行这个工具，拿到结果。
第五步，把工具结果回传给大模型。
第六步，大模型基于结果生成最终回答，或者继续调用下一个工具。

## 工具调用 tool calling
工具调用是 Agent 的基础能力。开发者用 JSON Schema 描述工具的名称、功能、参数。
大模型根据描述决定何时调用、传什么参数。
常见的工具包括：查询天气、搜索网页、读写文件、执行计算、调用数据库。

## Agent 和普通程序的区别
普通程序靠开发者写死的 if-else 决定流程。
Agent 由大模型动态决定下一步做什么，更灵活但更难预测。
因此 Agent 需要错误处理、重试机制、调用日志。

## 常见框架
LangChain、LangGraph、AutoGen、CrewAI。
