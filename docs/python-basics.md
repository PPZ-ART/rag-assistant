# Python 基础

## 变量
变量是存储数据的容器，用等号赋值，例如 age = 24。变量名要达意。

## 数据类型
- 整数 int：24、100
- 小数 float：3.14
- 字符串 str：用引号包住的文字

## 条件判断
if 条件:
    做某事
elif 其他条件:
    做其他事
else:
    都不满足时执行

## 循环
for i in range(1, 6) 循环 5 次。
while 条件 在条件成立时一直循环，可用 break 跳出。

## 列表
列表用方括号表示，例如 [12.5, 8, 20]。append 添加元素，len 数个数，sum 求和，下标从 0 开始。

## 函数
def 函数名(参数):
    return 结果
函数把一段代码打包，可以重复调用，避免重复写代码。
