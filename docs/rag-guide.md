# RAG 检索增强生成

## 什么是 RAG
RAG 全称 Retrieval-Augmented Generation，中文叫检索增强生成。
它解决的问题是：大模型只知道训练时的知识，不知道你的私有资料，而且容易编造（幻觉）。

## RAG 的流程
第一步，把文档切成小块（chunk）。
第二步，用 embedding 模型把每块文字变成向量。
第三步，把向量存进向量数据库。
第四步，用户提问时，把问题也变成向量。
第五步，在向量库里找出和问题最相似的几块。
第六步，把这几块资料和问题一起交给大模型，让它基于资料回答。

## 关键概念
- embedding：把文字转换成一串数字向量，意思相近的文字向量也相近。
- 余弦相似度：计算两个向量之间夹角的余弦值，值越接近 1 表示越相似。
- chunk 切块：文档太长不能整篇塞给模型，要切成小块，通常 200 到 500 字一块。
- 向量数据库：专门存储和检索向量的数据库，常见的有 chromadb、faiss、milvus。

## RAG 的价值
答案有据可查，减少幻觉。如果资料里没有答案，好的提示词会让模型直接说没有提到，而不是编造。
